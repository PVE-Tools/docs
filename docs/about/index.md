# 关于本站

本站是 [PVE Tools Pro](https://github.com/PVE-Tools/PVE-Tools-9) 的官方文档，收录脚本的使用方式、功能说明、高级教程与项目公告。

## 技术栈

| 技术 | 用途 |
|:---|:---|
| [VitePress](https://vitepress.dev/) | 基于 Vite 与 Vue 3 的静态站点生成器 |
| [Teek](https://vp.teek.top/) | VitePress 主题，提供代码块、面包屑等阅读增强 |
| Vue 3 | 赞助名单、定价表等自定义组件 |
| TypeScript | 站点配置与数据的类型约束 |
| pnpm | 依赖管理 |

## 基础设施

| 服务 | 提供方 |
|:---|:---|
| 托管与部署 | [Cloudflare](https://www.cloudflare.com) — 全球边缘网络静态托管 |
| 源码仓库 | [GitHub](https://github.com/PVE-Tools/PVE-Tools-9) — 版本控制与协作开发 |
| 域名与 DNS | Cloudflare — DNS 解析、DDoS 防护与安全加速 |
| 站内搜索 | VitePress 本地搜索 — 构建期生成索引，无运行时依赖 |

## 内容说明

- **文档语言**：本站内容以简体中文维护。
- **纠错与补充**：每页底部提供「在 GitHub 上编辑此页」入口，欢迎提交 PR。
- **历史内容**：已失效的项目公告与旧版协议保留在归档区，仅作留档，不代表当前状态。请以 [项目现状说明](./go-version-status.md) 与 [用户协议](../legal/ula.md) 为准。
